# Myntra Review Scraper project

Developed a Python-based Myntra Review Scraper to extract product reviews, ratings, and metadata for 
target and related items. 

• Utilized Beautiful Soup, Requests, and Regex to scrape data across product pages and handle pagination 
  dynamically. 

• Processed and cleaned reviews using Pandas, exporting structured data into CSV for further analysis. 

• Integrated basic NLP techniques to filter keywords and identify sentiment trends in customer feedback. 

• Enabled comparison of similar products based on review density and customer satisfaction for purchase 
  decision support. 
  
• Developed interactive visualizations using Power BI and Tableau for stakeholder analysis.
